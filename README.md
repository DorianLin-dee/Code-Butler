# Code-Butler

Code-Butler 是一个让0码vibe coding更顺畅的Skill，一个全方位的编程助手 Skill，解决了开发过程中代码修改前后的备份恢复、多语言版本同步不一致、以及需要反复确认执行等问题，实现了自动增量备份、智能上下文理解、多语言同步验证等功能，适合需要多平台开发的程序员使用。

## 功能特性

### 1. 增量备份机制
- 所有修改操作前自动备份
- 保留最近5步：backup/1 为最新，backup/5 为最旧
- 快捷命令：`b1-b5` 退回1-5步，`bi` 恢复到初始状态

### 2. 多语言同步
- 自动识别需要同步的语言版本
- 前置验证，避免运行时错误
- 平台特定检查（iOS/Xcode、小程序、Android、Web）

### 3. 暗号系统

| 暗号 | 含义 | 示例 |
|------|------|------|
| `c：` | 常量定义 | `c：用户端颜色是蓝色` |
| `cc：` | 改变常量 | `cc：让服务端与用户端一样` |
| `g：` | 全局应用 | `g：样式` |
| `l：` | 本地应用 | `l：样式` |
| `v：` | 立即验证 | `v：检查一致性` |
| `dry：` | 预演模式 | `dry：演示会改什么` |
| `must：` | 硬性约束 | `must：必须有点击事件` |
| `should：` | 软性约束 | `should：最好是红色` |

### 4. 约束条件协调
当多个约束条件无法同时满足时，自动：
- 识别约束类型（硬性/软性）
- 检测冲突
- 提供多个解决方案

## 安装使用

1. 在项目根目录创建 `.trae/skills/code-helper/` 目录
2. 放入 `SKILL.md` 配置文件
3. 在对话中告诉 AI "使用 code-helper skill"

## 文件结构

```
code-helper/
├── SKILL.md          # Skill 配置文件
├── README.md         # 说明文档
└── backup/           # 备份目录
    ├── 1/            # 最新备份
    ├── 2/
    ├── 3/
    ├── 4/
    ├── 5/            # 最旧备份
    └── initial/      # 初始状态备份
```

## 效果展示

**使用前**：
- 修改全局样式需要 5-6 次来回
- 运行后才发现错误
- 手动提醒同步多语言版本

**使用后**：
- 一次完成全局样式应用
- 前置验证避免错误
- 自动同步所有平台
